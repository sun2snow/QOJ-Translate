# QOJ-Translate

在 QOJ 题面中直接阅读中文翻译的 Tampermonkey 用户脚本，支持 HTML 和可提取文字的 PDF。

**[安装 / 更新脚本](https://github.com/sun2snow/QOJ-Translate/raw/refs/heads/main/qoj-translate.user.js)**

## 功能

- **HTML 原位翻译**：替换正文文本，保留图片、公式、代码、样例及页面结构。
- **PDF 中文阅读版**：重新排版译文，以原页裁剪保留图表、样例和复杂公式，并提供完整原页核对。
- **原文 / 中文切换**：切换不产生 API 请求。
- **顶部工具栏**：正常占位，不悬浮遮挡正文；设置使用独立弹窗。
- **缓存与继续翻译**：PDF 成功页逐页缓存，中途失败后可继续未完成页。
- **自定义 API**：兼容 OpenAI Responses 协议，支持配置服务地址、模型和密钥。

## 安装与使用

1. 在 Chrome 中安装并启用 Tampermonkey，按扩展提示开启用户脚本权限。
2. 点击上方安装链接。也可新建用户脚本，粘贴 [`qoj-translate.user.js`](./qoj-translate.user.js) 的全部内容并保存。
3. 打开 QOJ 题面，在正文上方工具栏点击 **⚙ 设置**。
4. 填写 API 完整地址、模型 ID 和 API Key，保存。
5. 点击 **翻译为中文**，完成后通过 **原文 / 中文** 切换。

无需 Node.js 或本地服务器。更新时覆盖原脚本后刷新页面，**不要先卸载**，以保留已有配置和缓存。

脚本不预设服务商或模型；已有版本保存过的设置仍会沿用。

## API 配置

需要支持 **OpenAI Responses API** 的服务，不是 Chat Completions 或 Gemini 原生接口。

| 配置项 | 说明 |
| --- | --- |
| API 地址 | 完整 HTTPS 地址，以 `/responses` 结尾，例如 `https://api.example.com/v1/responses`（仅为格式示例） |
| 模型 | 服务商提供的模型 ID，原样发送 |
| API Key | 使用 Bearer 鉴权，仅保存在 Tampermonkey 脚本存储中 |
| HTML 每批大致字符数 | 默认 8000，包含上下文；不是 token 数，也不是单个片段的严格上限 |
| 请求超时 | 默认 180 秒 |
| PDF 同时发送页图 | 默认开启，需要模型和接口支持 `input_image`，可能增加费用 |
| PDF 输出 token 上限 | 默认 16384，包含模型思考预算；实际支持范围由服务商决定 |
| PDF 格式错误自动修复 | 默认开启，每页每次任务最多一次，可能额外计费；截断不会自动补全或加大预算 |

首次调用时，如 Tampermonkey 请求跨域授权，请确认域名是你配置的服务。

## 常用操作

- **⋯ → 重新翻译**：确认后重新调用 API，可能产生费用。
- **继续未完成页**：PDF 失败或取消后可用，复用已成功页的可用缓存。
- **⋯ → 清除译文缓存**：不删除 API 配置。
- **ⓘ**：查看完整状态；错误详情会自动展开。
- **⋯ → 重置接口兼容记录**：重新尝试结构化输出能力。
- **⋯ → 导出 PDF 诊断**：手动保存最近一次 PDF 任务的诊断文件，不自动上传。

## PDF 说明

PDF 在浏览器本地解析，按页发送文字及可选页图，不上传原始 PDF 文件。

优先使用 JSON Schema 约束模型输出。仅当接口明确表示不支持时，才降级为 JSON 模式或提示词模式；所有结果仍须通过本地校验。格式兼容记录按接口与模型保存 7 天，可手动重置。

每页校验成功后立即缓存，全部成功后统一显示中文题面。中途失败不会用不完整译文覆盖原文。缓存因配额、淘汰或配置变化而不可用时，对应页面仍需重新请求。

**限制：**

- 不支持扫描版或加密 PDF；文件上限 40 MB、50 页。
- 图表裁剪坐标和数学转写由模型识别，可能漏图、裁偏或出错，**题目条件、公式和样例应以原页为准**。
- 裁剪区域是原图，其中的英文不会翻译；矢量内容会转换为屏幕分辨率的图片。
- 关闭页图后，不单独识别插图，完整原页会默认展开。复杂公式、多栏排版和特殊字体可能影响提取效果。
- 不同页面布局、模型及接口实现可能需要适配，不能保证所有题面都能无损转换。

## 常见问题

**找不到题面或 PDF 地址？**

确认题面已加载且有访问权限。在设置的高级选项中，可填写正文容器的 CSS 选择器或当前题目的 QOJ PDF 下载地址。不要选择 `body`、`html` 或包含导航、提交区域的整页容器。

**回复被截断？**

PDF 可适当增加输出 token 上限后继续；HTML 可减小每批字符数。脚本不会补括号后强行显示半份译文，也不会自动扩大输出预算。

**仍然无法解析 PDF 译文？**

在刷新前导出 PDF 诊断，查看失败页码、错误码和输出模式。诊断仅保留在当前页面内存，刷新后丢失；分享前请检查题面内容及其他隐私信息，**不要直接提交到公开仓库**。

## 隐私与费用

- 仅在点击翻译后向所配置 API 发送题面；PDF 默认还发送页图。重试和格式修复也可能计费。
- 密钥与缓存由 Tampermonkey 本地存储，**并非加密保险箱**。不要把真实密钥写入源码。
- API 请求不携带 QOJ Cookie；PDF 下载使用当前 QOJ 登录状态，不绕过访问限制。
- 请求设置 `store:false`，但服务商是否留存内容取决于其政策。
- 译文缓存最多约 80 条记录 / 300 万字符，PDF 按页记录，图片不写入缓存。
- 诊断不导出请求配置、鉴权头或输入页图，并对已知密钥脱敏，但模型回复仍可能含有题面信息。
- 外部依赖和数学字体来自固定版本的 jsDelivr 资源。`@connect *` 用于自定义 API；也可改为仅允许自己的服务域名和 `qoj.ac`。
- 使用前请确认赛事规则与题面使用权限允许向外部 AI 服务发送内容。

# QOJ 中文题面翻译（Tampermonkey）

面向 **Chrome + Tampermonkey** 的用户脚本。点击翻译后，在原题面位置显示中文，支持随时切换原文。

- 脚本：[qoj-translate.user.js](./qoj-translate.user.js)
- 默认 API：`https://cpa.072899.xyz/v1/responses`
- 默认模型：`gemini-3.8-flash-high`（原样发送，不擅自修改模型名或追加 thinking 参数）
- **只支持 OpenAI Responses 协议**，不是 `/chat/completions`，也不是 Gemini 原生 API。

## 安装与使用

1. 在新版 Chrome 中安装并启用 Tampermonkey。若扩展提示需要“允许用户脚本”或开发者模式，按其指引开启。
2. 打开 Tampermonkey → **添加新脚本**。
3. 删除编辑器内的模板，复制 `qoj-translate.user.js` 的全部内容，粘贴并保存。
4. 等待 Tampermonkey 下载脚本的外部资源，然后刷新 QOJ 题目页面。
5. 在右下角 **QOJ 中文题面 → 设置** 中填写 API Key，保存。
6. 点击 **翻译为中文**。如 Tampermonkey 询问跨域请求权限，确认允许访问你配置的 API 域名。
7. 使用 **查看原文 / 查看中文** 切换；切换本身不产生 API 请求。

安装和使用不需要 Node.js、npm 或本地服务器。不要把真实 API Key 写入源码、提交到仓库或发给他人。

### 按钮与设置

| 项目 | 行为 |
| --- | --- |
| 翻译为中文 | 先查本地缓存，未命中时调用 API |
| 重新翻译 | 确认后绕过缓存，再次调用 API；会先恢复原文 |
| 查看原文 / 中文 | HTML 恢复原文本节点；PDF 显示原来的阅读器或中文阅读版 |
| 取消 | 中止请求；不应用未完成的译文；服务端可能已产生费用 |
| 清除译文缓存 | 删除本脚本保存的译文，不删除 API Key |
| 每批大致字符数 | HTML 分批大小，包含上下文；不是 token 数，也不是单个超长片段的硬上限 |
| 超时 | 单个 API 请求的时限，默认 180 秒 |
| PDF 同时发送页图 | 默认开启，帮助模型识别公式、图表、样例；需要代理支持 `input_image`，并增加费用 |
| 高级设置 | 可手动指定题面 CSS 选择器和当前题目的 QOJ PDF 下载地址；只在当前页面生效 |

没有自动后台翻译。首次点击、重新翻译均可能产生费用；长题面分批、PDF 逐页串行请求。HTTP 408、429 和部分 5xx 最多自动重试两次；网络错误、鉴权失败、输出格式错误不会无限重试。

## HTML 处理方式

- 只修改识别到的题面内的文本节点，不重建整页，不执行模型生成的 HTML。
- 保留原 DOM 元素、链接、事件处理器、图片、SVG、公式、代码、`pre` 样例等。
- 渲染后的 MathJax / KaTeX 被跳过，未渲染的常见 TeX 定界符使用占位符保护。
- 段落被内联公式、粗体、链接切开的情况下，分别翻译文本片段并提供段落上下文。
- 应用译文前验证片段编号、数量和公式占位符；所有批次成功后才修改题面。
- 如果 MathJax 或网站脚本在翻译期间替换了文本节点，拒绝应用过期结果，提示刷新后重试。

为了保留原 DOM，不允许模型把片段内容跨内联元素任意移动，因此个别长句的中文语序可能不如完全重新排版自然。

## PDF 处理方式与边界

采用用户选择的 **B：中文阅读版**，不尝试修改 Chrome 内置 PDF 阅读器，也不生成新的 PDF 文件。

1. 从题面内嵌阅读器或下载链接获取 PDF，沿用当前 QOJ 登录状态。
2. PDF.js 在浏览器本地提取文字并渲染页面。
3. 默认向 API 发送每页文字及页图，不使用代理兼容性更不确定的原生 PDF 上传接口。
4. 模型返回中文段落，以及图表、样例、复杂公式的区域坐标。
5. 原图区域从浏览器本地渲染的 PDF 页面裁剪为 PNG，嵌入中文阅读版；普通数学表达式由 KaTeX 排版。
6. 每页附带可展开的**完整原页图像**；一键切换仍能回到原来的 PDF 阅读器。

**重要限制：**

- 不支持扫描版、加密 PDF。没有可提取文字的 PDF 会被拒绝。
- 模型区域识别不是精确的 PDF 版面解析，可能漏图、裁偏、重复区域或转写错公式。**完整原页始终保留，竞赛条件、公式与样例请以原页为准。**
- 被裁剪保留的图表、样例、复杂公式是原图，里面的英文不会翻译。图片内容不由模型重绘，但显示为屏幕分辨率的位图，不是原始矢量对象。
- 关闭发送页图后，只发送提取出的文字；不能可靠提取独立插图，所以完整原页默认展开，与中文一起显示。纯文本模式尤其不适合多栏、复杂数学或特殊字体的 PDF。
- 长句跨页、多栏文本、特殊字体/CMap、罕见数学符号可能影响提取和翻译效果。
- 首版限制 PDF 不超过 40 MB、50 页；页图长边最多约 1800 像素。完整文件仍需要先下载，PDF 与页图会占用内存。
- 代理须支持普通 `input_text`；默认 PDF 模式还须支持标准 Responses `input_image`。HTTP 400 时可先关闭页图排查，但没有真实服务调用验证之前，不能保证代理完整兼容。

PDF.js 使用固定版本的 ESM 资源，经本地 Blob 模块加载并使用 worker；不使用过时的 PDF.js 3.x UMD 构建。已额外禁用 PDF 字体动态 eval，也不执行 PDF 内嵌脚本。页面 CSP 或过旧的浏览器/扩展可能阻止模块加载，遇到明确的加载报错时请反馈错误文本。

## 题面识别与两道测试目标

目标页面：

- HTML：<https://qoj.ac/contest/4113/problem/20245>
- PDF：<https://qoj.ac/contest/4576/problem/22881>

默认识别 `#tab-statement article`、`#problem-statement`、`.problem-statement` 等常见 QOJ/UOJ 容器，并识别直接 PDF URL、`download.php?type=statement`、PDF.js `viewer.html?file=...`。

**开发环境直接访问上述 QOJ 页面返回 HTTP 403。尚未在真实 QOJ DOM、安装了 Tampermonkey 的真实登录会话和用户的 Proxy API 上完成联调。** 没有 API Key，也没有产生真实模型调用费用。本地浏览器测试中的这两个 URL 由合成测试页面拦截替代，不代表已验证线上页面。

若识别失败：

1. 确认处于题面标签页、页面已加载完成且有访问权限。
2. 在 Chrome 开发者工具中检查题面正文容器，复制它的 CSS 选择器，填入高级设置。
3. PDF 可在高级设置中填写该题在 QOJ 上的直接下载 URL（不是整个题目页面地址）。例如该目标题的下载形式为：
   `https://qoj.ac/download.php?contest_id=4576&id=22881&type=statement`
4. 仅指定题面区域，**不要使用 `body`、`html` 或包含提交/导航的整页容器**。
5. 如仍不工作，可提供不含密钥、Cookie 的错误文本及题面外层 HTML，用于调整选择器。

## 数据与安全

- API Key 存在 Tampermonkey 的脚本存储中，**不是加密保险箱**。不会写入题面、控制台日志或译文缓存。
- API 调用使用 Bearer 鉴权，匿名请求不携带 QOJ Cookie；拒绝 API 重定向以降低密钥被转发的风险。请使用支持 `redirect` 选项的新版 Tampermonkey。
- PDF 下载仅允许当前 QOJ 域名，并使用当前会话权限；不绕过登录、验证码或题目访问限制。
- 向配置的代理发送题面及可选页图。请求设置 `store:false`，**不能据此保证代理不记录内容**；留存规则取决于服务商。
- 缓存位于 Tampermonkey 本地存储，按源内容、模型、API 地址和处理版本区分，最多约 24 条记录 / 300 万字符。PDF 按页记录；图片不写入缓存，刷新后会本地重新渲染。
- 外部依赖和数学字体来自固定版本的 jsDelivr URL；不向 CDN 发送题面或 API Key。
- 模型输出只作为文本或经过数值校验的裁剪坐标使用，不把输出当作 HTML/脚本执行。
- 元数据中的 `@connect *` 用于允许用户自定义代理域名。若只使用默认服务，可自行移除此行，保留 `cpa.072899.xyz` 和 `qoj.ac`。
- 未结束的比赛可能禁止向外部 AI 服务发送题目。请先确认赛事规则以及题面的使用权限。

## 开发与测试

要求 Node.js 22+。运行：

```sh
npm ci
npm run check
npm test
```

测试包含：

- DOM 原位替换与精确恢复、图片/事件/代码/公式保留。
- 占位符、片段编号、输出 JSON 和 PDF 裁剪坐标验证。
- Responses JSON / 完整 SSE 解析，拒绝截断回复。
- API 请求字段、取消、超时和错误信息不泄露密钥。
- Chrome 中实际运行 PDF.js ESM、PDF worker、裁剪图片及 KaTeX。
- HTML / PDF 切换、缓存命中、文本模式、API 失败及取消后的原文保留。

浏览器测试默认使用 `/usr/bin/google-chrome`，也可以：

```sh
CHROME_PATH=/path/to/chrome npm test
```

找不到 Chrome 时只跳过浏览器测试。所有网络请求均在测试中拦截，GM API 使用桩实现；不访问真实 API、QOJ 或 CDN。因此这些测试不覆盖 Tampermonkey 扩展本身的权限、沙箱、跨域实现或 QOJ 线上布局。

`tests/fixtures/statement.pdf` 是自行生成的合成题面，含矢量插图和样例，不是用户提供的真实题目。`package-lock.json` 固定开发测试依赖，用户安装脚本不依赖 npm。
